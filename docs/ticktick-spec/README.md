# TickTick macOS reference research

These documents preserve observations of the installed TickTick desktop application from November 2026. They are reference evidence, not the Taskovsky product specification. Use the [Taskovsky documentation index](../README.md) for implementation instructions and the [dedicated parity tracker](../parity-implementation-status.md) for progress.

## Reading the evidence

- **Observed** means the running reference displayed a control or performed the stated action in the recorded environment. Seeing a control does not establish every behavior behind it.
- **Inferred** means a plausible interpretation that requires an experiment. **Unknown** remains a gap, not permission to invent a requirement.
- The initial captures were 2440 × 1330 raster pixels. Display scale and macOS logical point dimensions were not independently measured. Never equate screenshot pixels with points or use sampled JPEG colors as exact Taskovsky tokens.
- Reference account configuration affects dates, counts, access and visible settings. Personal task contents are omitted.
- Describing an excluded reference module does not bring it into Taskovsky scope. Earlier Taskovsky absence claims have been removed or superseded, without upgrading reference confidence.

## Environment and limits

The initial pass used macOS, the installed TickTick application, and light appearance on November 2, 2026; individual files record later probes. The initial app version, display scale, system font metrics, motion measurements and exact colors were not verified. Unknown gestures, controls, error states and edge cases remain unknown. The documentation reconciliation performed no fresh reference-app experiments.
