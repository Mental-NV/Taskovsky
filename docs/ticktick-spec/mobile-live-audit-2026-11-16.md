## Mirroring workflow note for the next session

Keep the Mac unlocked and iPhone Mirroring connected with TickTick visible. Select iPhone Mirroring in Computer Use. Its accessibility inspection identifies the Mac window. Use a live screenshot to locate phone controls inside that window, then coordinate taps for navigation. Use a fresh screenshot after drawer, menu and sheet transitions, since animation can move the controls. If input appears frozen, check the connection and make one bounded reconnect attempt if needed. Prefer a visible X or Cancel for drafts, and verify the starting screen is restored.
