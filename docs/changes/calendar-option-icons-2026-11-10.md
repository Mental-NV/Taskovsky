# CAL-DISPLAY-006 — Reveal hidden Calendar icons with Option

TickTick documents holding Option on Mac to temporarily show hidden Calendar item icons. The prior installed-app probe did not change the reference preference, so the documented behavior supplies the reference here. [Calendar View Options](https://help.ticktick.com/articles/7055782085826445312).

With Calendar visible in the key Taskovsky workspace window, holding Option temporarily restores the normal leading icons for all rendered item types. This applies to standalone Calendar and Calendar beside Tasks. Task checkboxes use the existing completion and reopening actions. Releasing Option or leaving the window restores the saved visibility. The option does not change Calendar settings, projections, colors or the dates and order of entries. Year has no entry-card icons. iPhone behavior stays outside this Mac keyboard interaction.

Verify with hidden task and note icons, including the master switch, that holding and releasing Option changes the visible controls only in Calendar. Verify that the normal checkbox action remains available while held and that settings remain byte-identical.
