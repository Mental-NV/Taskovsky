# MOB-HIERARCHY-001 Linked subtasks on iPhone

The November 9 local Tasks and Calendar scope includes the hierarchy in [BUS-006](../spec/business.md#bus-006), [IOS-006](../spec/iphone.md#ios-006) and [TT-005](../parity-implementation-status.md#tt-005). The isolated iPhone build adds subtask creation, independent completion, parent and child navigation, reparenting and detaching. Desktop and iPhone call the same graph operations. Desktop keeps its existing menus and file format.

Task detail shows a Subtasks section after the embedded checklist. It shows direct-child progress, 44-point controls and navigation to each record. A parent link opens the parent's detail, and Previous Task returns through the visited details. Tasks lists indent children within the current group. A child whose parent is outside that group stays visible as a top-level row.

Add Subtask focuses the native title input and saves on Add. The child inherits the parent's list and the configured insertion position. It has an independent status, description, schedule and checklist. The parent picker searches active tasks by title or list. Choosing a parent in another list previews the move before Done. Done moves the whole subtree in one workspace write. Top level detaches the selected task in its current list. Dirty Cancel offers Keep Editing and Discard Changes. Sheet drafts live in memory while open.

The shared graph rule rejects self-links, cycles and unavailable parents. The iPhone writer also checks the workspace revision and compatibility and locks archived or trashed records. Native fixture tests exercise a new child, independent completion, a cross-list move, relaunch, cancellation and detach. Repository tests cover refusal without a write, a move with a trashed descendant, configured placement and confirmation of a write that throws after replacement. The file audit compares task and settings data and reloads the same neutral files through Mac TaskStore. [Verification](../spec/verification.md#mobile-task-hierarchy).
