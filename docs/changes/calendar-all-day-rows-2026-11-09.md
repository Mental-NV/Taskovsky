# CAL-ALLDAY-001 — All-day rows in hourly Calendar views

Day, Week and Multi-Day can size the all-day strip automatically or reserve space for one to twelve visible rows. On Mac, drag the divider below all-day tasks to change the row count. The divider also supports accessibility increments and decrements. View Options offers the row count and an Automatic reset on Mac and iPhone. iPhone saves or discards the draft with Done or Cancel.

The setting affects layout only. All-day tasks below the selected row count remain available by scrolling within their date column. The timed grid and its rulers stay aligned with the resized strip. Dragging a task into its date column uses the existing scheduling action. A compact Mac window may show fewer rows than the saved preference so the hourly grid retains space. The saved preference applies again when the window has room.

The optional local Calendar setting stores the chosen count. Missing values retain Automatic and the default omits the key. The task file is outside this preference write. [Verification](../spec/verification.md#calendar-all-day-rows).

TickTick’s Week guide documents resizing the desktop all-day area from its bottom edge. The row steps, compact-window limit, local preference and iPhone settings control are Taskovsky choices. [TickTick Week guide](https://help.ticktick.com/articles/7055782149730861056#view-tasks)
