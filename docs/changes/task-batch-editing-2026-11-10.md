# TASK-BATCH-001 — Local batch editing from task lists

[Verification](../spec/verification.md#task-batch-editing).

TickTick documents selecting several tasks from a task list and changing their dates, priority, list, tags or completion status, or deleting them together. The exact native selector and command behavior were not observed in the installed reference. [TickTick batch editing](https://help.ticktick.com/articles/7055792921664028672).

- In List view, More Actions on Mac and Tasks Actions on iPhone open Select Tasks. The sheet displays the current list scope and a selection count, then stages one action for the selected items. Task rows retain their hierarchy in the selector. Back retains the selection. Cancel and dismissal discard the staged edit.
- Change Date moves the start to the chosen day using Calendar scheduling rules. Timed tasks keep their start clock in the display calendar and retain the length of their timed window. All-day ranges retain their civil-day span. Clear Date clears the window, reminders and recurrence using the existing unschedule policy. The date command requires tasks with valid schedules when assigning a day.
- Set Priority changes only selected tasks. Edit Tags adds or removes the chosen existing tags while preserving other references. Move to List offers active lists and Inbox. It carries descendants and follows existing section and parent-link rules. An archived selection can move to an active list or Inbox.
- Complete Tasks uses the existing completion rules, including recurrence and active descendant cascades. Already completed records remain unchanged. Move to Trash requires confirmation and uses recoverable Trash. Parent commands run before selected descendants so ordinary cascades do not run twice.
- An empty, stale, ambiguous, incompatible or unavailable selection is refused before publication. The batch is staged in memory and writes the workspace once. An identical change needs no write. A failed write does not publish the staged records or completion snapshots. Settings retain their original bytes. Mac checks the captured workspace and settings before applying. iPhone checks the workspace revision and preserves the existing protected-data gate.
- Validate the native selection, Cancel, persisted metadata and date/list edits, completion and confirmed Trash. Exercise mixed selections, archived records, dates and recurrence, failure, no-op, stale retry and exact saved-file preservation. Merge, sharing, permanent deletion and Calendar-specific batch controls are separate from this local task-list workflow.
