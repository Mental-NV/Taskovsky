# Mobile Calendar Arrange and scheduling

The phone uses the Desktop Calendar's local task commands. Arrange exposes calendar source scope, Inbox and active lists, optional overdue tasks, and list/tag/priority grouping. Rows open the shared task detail or a staged Calendar schedule editor seeded from the focused day. Actual Calendar cards support schedule editing, move, resize and removal. Recurrence previews open their source task and carry no scheduling affordance.

Calendar edits preserve existing point/range shape and use the shared Calendar reminder and recurrence policies. Untouched Done and Cancel leave the workspace bytes alone. A scoped Undo restores schedule fields, retains unrelated edits, and refuses a changed schedule, status, archived record or deleted record. All successful phone edits use the local repository and leave settings untouched.

Use native touch and accessibility controls for a narrow screen. Keep the desktop layout and external calendar integrations out of this change. Record the verified interactions, persistence and any gesture limits separately.
