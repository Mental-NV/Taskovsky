# MOB-PREVIEW-001 — Isolated read-only iPhone preview

Status: Implemented for the bounded cases below; current evidence/limits are in [verification](../spec/verification.md#mobile-foundation-preview). Authorized under the autonomous local mobile parity request. Depends on MOB-FOUNDATION-001, IOS-008/012/014. This bounded slice advances S3's immutable reading and S4 shell; it does not enable writes or satisfy full S3/S4 exit gates.

Create a local Xcode iPhone target with iOS 17 deployment setting and only portable Domain/Workspace dependencies. No developer account, provisioning credentials, entitlements, notifications, integration or network calls. Use a clearly labeled bundled neutral preview fixture in Debug, empty read-only state in Release. Never open the Mac workspace or use copied private reference text. Bundle reads and selection/view state produce no workspace/settings persistence calls.

Read sessions retain original workspace/settings bytes. Decode failures show an unavailable-data screen rather than writable empty data. Valid plain bodies are selectable read-only; rich or mismatched companions get an explicitly labeled plain preview and are retained without extraction. No edits, lifecycle, import, recovery overwrite or Add button until the writable-repository gate is independently implemented and verified.

UI follows IOS-002/003 reference geometry where applicable: cool semantic page background, 16-point card insets/corners, circular 44-point accessible toolbar targets, 48-point default row pitch, rounded-square status glyph and three-destination bottom capsule for Tasks/Calendar/Search. Drawer has indigo background and neutral identity. Detail uses a half/large sheet; read-only body state is explicit. No inert editing controls, Matrix, attachments or screenshot-only route.

Provide working read navigation for smart/list/tag/filter destinations, detail, organization search and seven Calendar modes using shared projection/dates. Sorting/grouping, Board, Summary, advanced search criteria, full display controls, Arrange and editing are explicitly incomplete adaptations. View-only Calendar filters can use the corrected domain commands in transient phone state; four-zone values must survive snapshot reading. Year date opens Week and month title opens Month. No independent recurrence algorithm.

Acceptance: macOS regressions and release build after extraction; iOS 17 compilation; simulator build/run with exact device/OS, neutral fixture and screenshots; Tasks→detail→Calendar→Search navigation and no-write session evidence. Exercise unknown fields elsewhere, malformed rich ranges/mirror, unknown enum and unreadable settings in read-session tests. Record small/large text, VoiceOver, dark and reference comparison limitations; do not claim near-pixel-perfect or complete parity from one screen.
