# CAL-MONTH-ZOOM-001 — Flexible iPhone Month grid

The iPhone Month grid can show the full month, three weeks, two weeks or one week. Spread two fingers on the days to zoom in or bring them together to zoom out. Zoom buttons offer the same steps. The four levels show up to two, four, six or eight tasks per day. Overflow still opens Day. Dragging a task onto a date uses the same scheduling action at every zoom level.

The zoomed grid starts with the current focus week and uses the configured week start and local calendar. Previous and Next move by the visible number of weeks, including across month boundaries. Today returns to the current week at the same zoom. Returning from a different Calendar mode starts at Full Month. The zoom choice is temporary and does not write tasks or preferences. Selecting Month continues to save the ordinary mode setting.

The [TickTick release notes](https://help.ticktick.com/articles/7082552170989486080) describe fewer weeks and more tasks per date when zooming the mobile Month view. The zoom steps and focus behavior above are Taskovsky’s choices. [Verification](../spec/verification.md#mobile-calendar-month-zoom).
