# CAL-MOBILE-ARRANGE-DRAG-001 — Drag a task from Arrange into Calendar

In iPhone Day, Week, Multi-Day, Month and Multi-Week, Arrange Tasks opens at half height when that presentation is available, with part of Calendar visible. Hold a task grip and drop it on a visible date, all-day strip or time. A timed drop uses the same quarter-hour grid and duration rules as an existing Calendar card. Date and all-day targets use their existing local scheduling rules. The task keeps its list, hierarchy, body and other unrelated fields. An outside release preserves the task’s schedule. A saved schedule change offers Undo, and a recurring task follows the existing occurrence or series decision.

Scroll the Arrange list at half height or use the grabber to expand it for browsing. The panel retains task detail, grouping, scope, overdue inclusion and the precise Schedule button. Agenda, Year and full-height presentations use the precise editor. The existing compatibility, archived-task, revision and private drag checks apply. The change is local to iPhone presentation and uses the existing shared Calendar scheduling operation.

The [TickTick FAQ](https://help.ticktick.com/articles/7055792921664028672) documents dragging from Arrange Tasks onto a date on mobile. Taskovsky uses its existing local Calendar drop targets, scope and Undo rules. The active Tasks and Calendar parity goal authorizes the change.
