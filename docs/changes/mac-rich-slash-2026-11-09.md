# Mac description slash menu

TickTick’s desktop formatting guide documents typing a slash to open a shortcut menu. [TickTick formatting guide](https://help.ticktick.com/articles/7507338582718152704)

In Taskovsky’s editable Mac description, type `/` at the start of the text or after whitespace. The native menu opens at the caret and offers Heading 1–6, quote, bullet and numbered lists, checklist, horizontal rule, bold, italic, underline, strikethrough, highlight and inline code. Each item invokes the same native editor command and Undo as the corresponding toolbar control.

A formatting choice consumes the shortcut without inserting the slash. Dismissing the menu in the same editor types the slash normally. A slash within a word or URL and pasted slash text use the usual text input path. Selection and marked text retain their regular editing behavior. This is a Mac keyboard shortcut. Links and clearing styles remain in the toolbar, and mobile keeps its native formatting controls.
