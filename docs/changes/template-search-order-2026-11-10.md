# TASK-TEMPLATE-002 — Find and reorder local templates

Search the template manager or chooser by name, task title, description or checklist text. Search ignores case, accents and surrounding whitespace. The results retain their saved order and the search stays in the current view. Capture and apply keep their existing confirmation and content-preservation rules.

Clear the search to reorder templates. On Mac, drag a card's grip onto another card to move to that position. Move earlier and Move later are available in the card menu. On iPhone, choose Reorder in Manage Templates and drag the native row controls. The change saves only the order of existing template records. It preserves their IDs, rich descriptions, checklists, recurrence, schedules and other fields. The save checks the prior order, and the iPhone also checks the workspace revision. Releasing outside a target preserves order.

TickTick's June 3 release notes document search and drag reordering. The search fields and local save rules above are Taskovsky choices under the active Tasks and Calendar parity goal.
