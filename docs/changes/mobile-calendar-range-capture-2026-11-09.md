# Staged iPhone Calendar range capture

9 November 2026 · CAL-RANGE-CREATE-002

Hold an empty date cell in Month or Multi-Week, then drag to another date. The Calendar grid highlights the inclusive selection and opens the regular task capture sheet on release. Dragging backward uses the same date order. Releasing on the starting date or outside the grid leaves the capture sheet closed.

The draft contains editable Start and End dates. Use end date only converts the draft to a dated point, and No date clears the schedule. The selected range takes precedence over date text or a template’s duration. A title such as “Retreat tomorrow” retains the date words. The destination, existing tag, and priority controls use the ordinary capture flow.

The recovery file stores the explicit range with the draft. Relaunch offers recovery and waits for Add. Cancel leaves the workspace alone. Add uses the existing revision-checked creation transaction and stable task identifier. Older draft files omit the optional range field. Older readers use the existing exact-decoding guard to protect drafts with unfamiliar fields.

The Month overflow control opens Day. Ordinary swipes scroll the grid, pinch changes Month zoom, and an existing task’s grip remains the move control. Calendar account integrations are deliberately deferred. [Scope decision](../ticktick-spec/taskovsky-parity.md#calendar-integrations-deliberately-deferred--8-november-2026).
