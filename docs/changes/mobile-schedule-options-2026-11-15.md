# Schedule Reminder and Repeat structural pages

Wide-first D10/D12 slice: root Schedule shows compact Reminder and Repeat summary rows rather than entire inline editing sections. Each opens a dedicated page containing the same supported controls over the same outer staged edit. Back retains draft changes; outer Cancel discards and outer Done saves. Existing custom repeat sheet, replacement warning, automatic/manual/end reminders and occurrence skip remain. No new preset, recurrence, reminder delivery or persistence semantics.

This is partial structural coverage: reference uses anchored presets and nested dialogs, while Taskovsky uses pushed forms for its existing settings. Exact popup styling, reference repeat-type mapping and reminder preset defaults remain open. Unsupported external/notification controls are not added.
