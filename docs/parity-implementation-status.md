# TickTick feature parity tracker

This is the **canonical progress tracker** for Taskovsky's feature comparison with TickTick. It is separate from the [Taskovsky business specification](spec/business.md), [UI/UX specification](spec/ui-ux.md), and [TickTick research notes](ticktick-spec/README.md). Use it to decide what exists, what differs, what still needs evidence, and what belongs to a later implementation task.

Taskovsky source baseline: `30045bac5355b793a8c155b87ffe58584cb29fb8` (main). Documentation review date: 2026-11-08. Source was inspected directly; no application build, automated suite, macOS UI session, or new TickTick experiment was run for this refresh. Existing tests are evidence of coverage intent, **not a current pass**. Historical test totals and build/live-QA narratives are preserved in the [implementation history](archive/parity-implementation-history.md), not repeated as current gates.

## Reading and maintaining status

Stable `TT-###` IDs identify comparison areas. `BUS-###` links define Taskovsky's current behavior; those rules are not inferred from TickTick. Preserve IDs when a row is split or resolved, recording successor IDs rather than reusing the old number.

**Taskovsky implementation status**:

- **Code present:** the named capability has a source path. This is not proof of a working end-to-end flow, feature completeness, or equivalence to TickTick.
- **Partial:** meaningful source exists, with a known missing capability or narrower behavior.
- **Not implemented / undecided:** no current capability; whether to add it has not been approved or specified.
- **Excluded:** outside the current Taskovsky scope; reference research does not authorize implementation.
- **Proposed:** future design/decision only, with no current implementation claim.

**TickTick evidence confidence** describes the linked observation, not the entire feature:

- **O — observed:** a historical macOS screen or specified action was observed. Confidence is higher for that particular action; unexercised controls remain unknown.
- **S — static:** retained investigation report records shipped labels/model/metadata or decompiled control flow. It supports capability shape, not complete runtime semantics. The raw local analysis bundles are not part of this tracked repository, so this refresh did not independently reproduce that analysis.
- **D — historical documentation:** earlier audit/reference text is available but may be narrower or less directly reproducible. Treat as a research lead.
- **U — unknown:** no sufficiently specific comparison evidence is recorded; a Taskovsky implementation must not be labeled equal by assumption.

No row is marked “parity verified” in this refresh. Closing a gap requires the relevant Taskovsky result at a named revision plus a bounded TickTick comparison, or an explicit decision to accept a documented difference. There is no meaningful overall completion percentage while scope and reference behavior remain incomplete.
