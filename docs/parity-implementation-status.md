## Measured palette and geometry

User-approved screenshot analysis gave the light-mode tokens now used via shared helpers (dark mode keeps adaptive behavior): blue accent #5171F2, card #FAFAFA, body #191919, secondary values #737373, explanatory text #A0A0A0, checkbox outline #C8C8C8 (settings), no-priority task outline ~#9C9C9C (same-display visual estimate, not a measured claim). Stored user tag/list colors are never altered. Geometry policy: rail 62, sidebar 160-320 manual, center minimum 300, docked detail minimum 280, overlay drawer fixed 300, pop-up window 464x630 with a 52pt header. The exact TickTick dock threshold is unknown (derived rule brackets the observed 757 overlay / 961 docked transition); 757 is below the 780 minimum content width, so compact behavior holds at 780.
