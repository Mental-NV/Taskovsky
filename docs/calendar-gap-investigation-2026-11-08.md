## Local behavior contract

- Configure up to **three additional rulers**, a Taskovsky width/layout limit; TickTick's limit is unknown. Each row stores an IANA identifier and optional label (trimmed, at most 32 characters). Blank labels use the zone abbreviation for the first displayed date. Invalid IDs and duplicate identical IDs are removed while preserving order. Different regional IDs with equal current offsets remain distinct.
- Current Calendar zone is displayed separately and cannot be edited in this dialog. A configured row matching it is retained but its duplicate ruler is hidden, so changing the main zone does not discard configuration.
- Time Zone Settings works on a local draft. Add, replace, label, order and remove do not persist until Save. Cancel/Escape discards the entire draft. Choosing a city uses search, native list selection and Choose/Return; Cancel in that child picker preserves the parent draft.
- The visibility switch is independent from saved rows. Turning it off keeps labels/order. Turning it on with no rows opens configuration. Saving configuration while visibility is off leaves rulers hidden. No task, recurrence, reminder or primary-zone value is changed by these preferences.
- Day, Week and Multi-Day display every enabled secondary ruler in configured order, then the primary ruler. Foundation converts the primary first-day wall-hour instants to each secondary zone. Hover text includes the secondary date, addressing previous/next-day hours. As with the baseline, a multi-day view's ruler is based on its **first date**; a DST transition later in the range can have a different offset. No claim of independent per-column rulers is made.
- Existing single `additionalTimeZoneID` settings migrate to one enabled, unlabeled row. New collection keys take precedence, including an explicitly empty collection. Hidden collections survive save/reload. A compatible single visible ID is also encoded for older readers.
- Year style is independent from card style. Standard shows item dots; Heatmap shades by the existing visible-entry counts. Both preserve date selection/drill-down. Show Item Icons defaults on and does not change counts, filtering, task completion state or projection.
